# Schoolprojects

A collection of my school projects from my software development studies at Savonia University of Applied Sciences, gathered into one repository.

| Folder | Contents |
|---|---|
| [`Miscellaneous`](Miscellaneous) | Early work in plain C#, WinForms and Java |
| [`Web`](Web) | HTML, JavaScript and React projects |
| [`.NET`](.NET) | .NET assignments in C# |
| [`Java`](Java) | Object-oriented programming exercises, exams and Java web programming |

Each folder has its own README with more details.

These folders were originally separate repositories. They were merged here with their full commit history, so the original commits are still visible in `git log`.

Group projects are mostly left out, because it is hard to separate my own work from my teammates'. The exception is my final group project, [Soitinlainaus](https://github.com/EliasNiskanen/Soitinlainaus), which has its own repository.
