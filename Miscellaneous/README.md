# Miscellaneous

My earliest programming work: basic C# console exercises and Windows Forms applications from my first courses. Most of these were written straight from the assignment, so they have little documentation, but they show where I started.

Group assignments are left out, because it is hard to separate my own work from my teammates'.

## Projekti

C# console exercises from my first programming course, grouped by theme (`Teema 1`–`Teema 6`). They cover variables, user input, conditionals, loops, random numbers and reading and writing files, plus a few exam tasks (`Tentti`).

## WinForms

Small Windows Forms applications from a user interface course.

- **Viikko 2–3 tehtävät** – weekly exercises practising forms, buttons, text fields and event handling.
- **Forms projekti 1** – a form for entering and browsing person records.
- **Käyttöliittymä projekti 1** – a user interface course project.
- **Ristinolla** – a tic-tac-toe game.
- **xyohjelma** – a small program that swaps the values of X and Y.
- **WindowsFormsApp1, WindowsFormsApp2** – practice applications.
