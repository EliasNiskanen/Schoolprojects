# .NET

Individual assignments from a C# / .NET course. Each task builds on the previous one, from a console application to a full ASP.NET Web API, and each comes with automated tests (`test/t1`–`t5`) used for grading.

Group assignments are left out, because it is hard to separate my own work from my teammates'. My final group project, [Soitinlainaus](https://github.com/EliasNiskanen/Soitinlainaus), has its own repository.

| Folder | Description |
|---|---|
| `task-01` | **Console app** – a calculator class used from a console application. |
| `task-02` | **Class library** – a shapes library used by a separate console app. |
| `task-03` | **Entity Framework** – reverse-engineering an existing database and querying it with EF Core. |
| `task-04` | **ASP.NET Razor Pages** – a phone catalogue web app (RazorPhones). |
| `task-05` | **ASP.NET MVC** – the same phone catalogue built with controllers and views (MVCPhones). |
| `task-06` | **ASP.NET Web API** – a REST API for university course enrollment (UnivEnrollerApi). |
| `demo` | A demo repository for practising the GitHub Classroom workflow. |

Each task folder has the original assignment README with the detailed requirements.
