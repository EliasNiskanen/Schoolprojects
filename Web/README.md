# Web

Front-end work from my web programming courses: first plain HTML, CSS and JavaScript, then React. The React projects use components, hooks, React Router, React Bootstrap, data fetched from a json-server mock API, and Jest tests.

| Folder | Description |
|---|---|
| `Tehtävät html` | My first web exercises: numbered HTML, CSS and JavaScript tasks building up from basic pages to DOM manipulation. |
| `ekaviikko` | Week 1 of the React course: first components, props and state with an animal list and a counter button. |
| `tokaviikko` | Week 2: fetching and updating data from a json-server mock API. |
| `kolmasviikko` | Week 3: a data table with Bootstrap styling and a global search filter. |
| `testaukset` | Writing unit tests for React components with Jest and React Testing Library. |
| `Sekalaista` | Smaller React exercises (React1–React7). |
| `omaApi` | A minimal Node.js HTTP server. |
| `harkkatyö` | Course project for Web Programming 2: a React app with routing for listing, adding and editing items and a contact page, with tests. |
