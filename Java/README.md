# Java

Java work from object-oriented programming and Java web programming courses, from small console programs to Spring Boot web applications.

## Java harjoitukset

Small console programs: a VAT calculator, BMI calculator, leap year checker, temperature converter, circle area, a lottery number generator and a hangman game.

## Kalastuskoetehtävä

An exam task in object-oriented programming: fishers and their catches, with helper methods for catch statistics.

## Ostoskorikoetehtävä

An exam task on inheritance: a shopping cart with a `Tuote` (product) base class and subclasses for clothing, appliances and food.

## Java Web Programming

Spring Boot web applications built around a measurement data theme.

- **Task1** – a REST API for measurement data with a Spring Data repository.
- **Task2** – adds a service layer and HTML pages for listing, adding and editing measurements.
- **Task3** – adds measurement locations as a second entity linked to the measurements.
- **Task4** – uploading, listing and deleting images.
- **Vaadin** – a Vaadin application with login and user roles, views for measurements and patients with editing and deleting, and a search view.
