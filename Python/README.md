# Python

My early Python exercises from an introductory programming course: small console programs practising input and output, conditionals, loops, lists and functions.

| File | Description |
|---|---|
| `Viikko1_kotitehtävät Elias Niskanen.py` | Week 1 homework: variables, data types, reading user input and printing it. |
| `7Rubikin kuutio.py` | Reads five Rubik's cube solve times and calculates the official competition result by dropping the best and worst time and averaging the rest. |
| `8aikataulu.py` | Asks for the current time and prints the next three departures from a fixed bus timetable. |
| `8vaihtorahat.py` | Calculates change for a purchase and breaks it down into 10, 5, 2 and 1 euro notes and coins. |
| `kivipaperisakset7.py` | A two-player rock-paper-scissors game. |
| `hirsipuu.py` | A hangman game where one player enters a word and the other has ten letter guesses to find it. |
